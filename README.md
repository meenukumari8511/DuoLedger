
# DuoLedger

### Mine. Yours. Ours.

An AI-powered financial management platform designed for couples.

## 1. About the Project

DuoLedger helps couples manage their individual finances
while collaboratively managing shared household finances.

It focuses on financial transparency, individual privacy,
shared expense management, and future financial planning.

## 2. Main Objectives

- Manage individual income and expenses.
- Track shared household expenses.
- Calculate mutually agreed contributions.
- Manage budgets and savings goals.
- Maintain individual financial privacy.
- Generate AI-powered financial insights.
- Predict future cash flow.

## 3. Planned Technology Stack

- Frontend: Next.js and TypeScript
- Backend: Python and FastAPI
- Database: PostgreSQL
- ORM: SQLAlchemy
- AI/ML: Scikit-learn and PyTorch
- Version Control: Git and GitHub

## 4. Project Status

Currently in the initial development phase.

## 5. Project Structure

- frontend/ - User interface
- backend/ - Application logic and APIs
- docs/ - Project documentation

## 6. Project Vision

To help couples build a transparent, collaborative,
and financially independent future.
